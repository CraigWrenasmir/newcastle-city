# Newcastle City

A 90s-style website with modern twists, built by Craig and his daughter.

Page one: Newcastle Harbour fishing. A full-photo page with a 3D skill bar
(red at the ends, green in the middle). Press Cast, then hit SPACE, click or
tap when the marker is in the green to catch a fish.

Plain HTML/CSS/JS, no build step. Open `index.html` or visit the GitHub Pages site.
